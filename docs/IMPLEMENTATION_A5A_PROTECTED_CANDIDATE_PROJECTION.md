**Intent:** the next security-critical operation is **verified reading**, not a write/cutover. `backend/app/g1c_projection.py` authenticates every outer AES-GCM `canonical_source_mirrors.payload_json`, validates domain-separated HMAC source identity by original table/primary key, strictly checks known source tables/columns, reconstructs date/time field types and verifies the *entire* encrypted source graph and independent owner/account/year signed-movement HMAC against a read-only census of the ORIGINAL synthetic PostgreSQL source. It refuses duplicates, surplus/missing rows, tampering, wrong keys, changed source or unknown schema; any failure is fail-closed with redacted errors.

`inspect_restored_sealed_candidate()` reads only the AES-GCM **mirror table** from independent `synthetic_restore_*` PostgreSQL clone using REPEATABLE READ READ ONLY. It compares the result with the separate `synthetic_*` original source census, with a second original-source recheck. **It never SELECTs plaintext economic legacy tables on the restored clone**, never writes a source or candidate, never changes operational app reads, does not encrypt/retire old legacy finance columns and never asserts tax/net worth/filing readiness. The existing candidate *still contains plaintext legacy tables* and is **not G1-ready**, nor a typed canonical active bank ledger.
