## Engineering execution rules

1. Finish at least one concrete, owner-independent gate at a time; preserve modular CFO scope without introducing unused microservices or premium services. Link each PR to its gate, tests and risks.
2. Build and test real-format **adapters with synthetic variants now**. Request the genuine documents only when private intake exists and actual acceptance needs them.
3. Never certify a security gate from mere encryption of a second copy, or a tax gate from a hypothetical salary-slab preview. Verify the active read/write path and legally relevant source facts.
4. Keep a single canonical [project status](PROJECT_STATUS.md) and [handoff](CURRENT_HANDOFF.md) with latest validated SHA and exceptions. Follow [mandatory continuity protocol](CHAT_CONTINUITY_PROTOCOL.md) before a new chat or thread ends.
