- `personal-cfo-frontend-preview` is the **sole internet-reachable** service, on `https://personal-cfo-frontend-preview-development.up.railway.app`; it serves synthetic public installable PWA via Nginx. `frontend/nginx.railway.conf` proxies **only** `GET /api/preview/status` to the internal preview API. It is NOT the authenticated `app.main` finance app. Do **not** generate a public domain for this service.
- PostgreSQL 18 is private, with existing persistent volume mounted on the **database** service; the API service has **no volume**. The P1C AES-GCM SQLite vault requires an owner-only private local path and is **NOT an approved, durable Railway credential store**; copying localhost flags or a SQLite file into the ephemeral container is insecure.
- `APP_DATA_MODE=synthetic`; G1 canonical migration, G2 actual owner MFA/private token custody/offsite recovery, G3 authentic original source processing still blocked. Existing ChatGPT Google Drive connector & daily metadata automation are NOT PWA Google OAuth.

In the **existing** `personal-cfo-drive-connector` Google Cloud project, navigate **Google Auth Platform → Clients → existing Web application OAuth client → Authorized redirect URIs** and **ADD** (do not replace until verified):

`https://personal-cfo-frontend-preview-development.up.railway.app/api/drive/oauth/callback`

**This exact public HTTPS URI is PROPOSED for the future deployed route, NOT LIVE.** It must match exactly the `redirect_uri` sent to Google; no trailing slash and no URI query. Leave the prior `https://localhost:8443/api/drive/oauth/callback` temporarily if Google allows it, do not run localhost consent. JavaScript origins stay blank for server-side OAuth; `https://www.googleapis.com/auth/drive.metadata.readonly` scope and dedicated-account test user unchanged. Do not disclose client secret or add Google keys to public frontend, GitHub, ChatGPT or synthetic Railway variables. **Do not click Connect/authorize yet**: no functioning cloud callback or secure session exists.

**Potential Google limitation:** Google OAuth brand/domain verification requires ownership of app domains, and a shared `*.up.railway.app` domain may not be verifiable by the owner for formal production/restricted-scope approval. If Google refuses the shared domain, STOP and choose an **owner-controlled verified custom domain** mapped to the existing frontend service (no automatic purchase or provisioning); the eventual callback URI must then match that new domain exactly. External Google OAuth app in Testing with Drive metadata scope typically has a 7-day refresh-token lifespan; production/personal-use or restricted-scope policy must be assessed before promising unattended indefinite sync.

Implement separately approved encrypted storage with single-use state, safe multiworker transactions, key custody/rotation, revoke and independently tested recovery. Read-only scope cannot download original PDF/Excel; original content reconciliation requires separately reviewed G2/G3 and appropriate scope/owner consent.
