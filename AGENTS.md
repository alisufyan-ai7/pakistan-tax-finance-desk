## Non-negotiable rules

1. **Resume, do not restart.** Check the current GitHub `main`, `AGENT_START_HERE.md`, `docs/PROJECT_STATUS.md`, the **latest section** of `docs/CURRENT_HANDOFF.md`, `docs/PROJECT_DECISIONS_AND_SCOPE.md`, `docs/CFO_PLATFORM_ARCHITECTURE.md`, `docs/REQUIREMENTS_COVERAGE_MATRIX.md`, open issues/PRs and exact-head GitHub Actions. Historical handoff sections might be superseded. Never assume a previous chat's result is merged without verifying it.
2. **Every chat must leave GitHub complete.** At each milestone, commit code, tests, evidence of CI, architectural decisions, constraints, important discussions, remaining tasks, blockers and explicit next steps to the repository. Update `docs/PROJECT_STATUS.md`, `docs/CURRENT_HANDOFF.md`, `AGENT_START_HERE.md`, and pertinent scope/roadmap docs. Create/update issues for unfinished work. **Before the chat approaches its length limit, publish a committed handoff; the next chat must be independently restartable from GitHub** without the user pasting transcripts.
3. **Owner-independent work first.** Use synthetic fixtures, small cohesive PRs, cost-aware CI and available connected tools; do not request historical returns, bank statements, credentials or owner approvals merely to continue independent engineering. Ask only when an actual external permission, private evidence, live deployment or material irreversible choice is required.
4. **Keep genuine personal financial data private.** Repository intentionally PUBLIC only for synthetic source, tests and documentation during development. Never push CNIC/NTN, account or tax-return data, actual bank files, secrets or authentic personal evidence. Real-data mode currently fails closed. Neither authenticated encryption for new events nor migration rehearsal encrypts *all old legacy numeric/date metadata*. Preserve the P0 privacy gate and independent backup/recovery acceptance.
5. **Accuracy and legality.** No fabricated FBR liabilities, deductions, source documents, tax savings, investment returns or net worth. Legal tax reduction and compliant optimization only; no concealment, evasion or forged evidence. Track statutory rule-year versions and independent evidence. Distinguish historical cost arithmetic from taxable gains, declaration from verified bank/source evidence, projections from facts and unknown from zero. AI does not act without authorization.
6. **Design for an expandable personal CFO.** Single-owner private product first; modular monolith with clean domain contracts. Cover banks, spending, recurring bills, salary/business/rent/investment income, loans given/taken, cash, gifts/zakat/donations, withholding, assets, investments, insurance, goals, planning, scenarios, FBR income/wealth returns and lawful opportunities. Future household/accountant and multi-tenant SaaS are design options, not launch blockers. Do not overbuild microservices.
7. **Proof-based delivery.** Never state code is merged or tested without exact PR/commit/CI verification. If incomplete, describe what was done and what remains. Preserve invariant/property/security tests. Maintain rollback and documented provenance.
